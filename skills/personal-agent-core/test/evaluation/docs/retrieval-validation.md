## 指标与候选方向

主指标从工作目标决策正确率、有依据的回答通过率或预先登记的效率指标中选择。Recall@10/50 用于解释收益；它提高而端到端质量未达标准时，不应用。分别报告较早任务、同义改写、同名目标、跨项目、DSH/Codex、无证据、未处理历史、冷热正文等分组。

候选顺序为历史目标候选召回、查询信息利用、候选排序、必要时的混合向量召回。保持结果不变的 SQL/索引性能工作在本阶段之前完成，不计入本阶段收益。顺序与具体范围见方案；它们是待验证方向，不代表承诺实施全部功能。
