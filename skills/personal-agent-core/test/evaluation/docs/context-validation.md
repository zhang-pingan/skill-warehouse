### 必须保护的行为

- 当前用户要求保持其原有优先级，历史证据、候选和来源中的指令不获得额外授权。
- 已撤回、已取代、过期及冲突内容按请求时点正确处理，无跨项目混入。
- 现有目标继续原会话；新 worker 仍遵循模型识别 DSH 插件工作或配置默认值的两分支规则。
- 实际交给模型的内容可从日志重建；DSH/Codex 收到的必要来源可读，不只获得无法解析的内部 ID。
- 同一请求及重试不重复排队；新请求和压缩后继续不会因永久去重而遗漏必要信息。
- 页面打开、空闲轮询、主会话重复获取不产生新上下文输入。
- 版本变化、并发、重启、取消和主会话切换不会回写过期上下文或恢复旧目标。
