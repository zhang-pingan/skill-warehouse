## 确认设计与后续进入条件

[确认设计](confirmation-design.md)已冻结来源族作为独立单位、三次成对重复、质量提升至少 5 个百分点、效率改善至少 20%、关键回归为零，以及延迟/token 的保护规则。使用有界成对经验 Bernstein 区间，跨候选显著性预算为 `0.05/[j(j+1)]`，不按中途成绩停测或扩样。
