# 优化确认样本设计

本设计规定检索优化和任务上下文优化在应用前需要什么证据。冻结设计是 B0 的准备条件；生成足量未见来源族、比较固定候选并通过全部门槛，是以后应用优化的条件。B0 不需要先完成一个尚不存在的优化候选。现有 12 族封存集、48 族探索与验证集不能据此宣称已具有确认 5 个百分点收益或 1 个百分点非劣的统计功效。

机器可读规则在 [confirmation-design.json](confirmation-design.json)，数值由 [confirmation-design-analysis.js](confirmation-design-analysis.js) 计算，已执行结果在 [confirmation-design-analysis.json](results/confirmation-design-analysis.json)。本设计和计算没有读取封存题目、没有运行封存集，也没有修改生产行为。

## 样本与可推广范围

独立单位是来源族。同族的问题、改写、三次模型重复和 worker 多轮执行先聚合，不能分别当成独立样本。对质量指标，版本内先平均同族预先登记的合格题目及三次重复，得到 0 到 1 的族分数；再计算候选减对照的族差值。各族等权，差值范围为 −1 到 1。失败、超时、解析错误和拒绝请求留在分母和资源记录中。

确认对象是预先规定的合成场景来源分布，不代表所有真实用户历史。后续来源族必须在候选固定后按预登记方式生成或纳入，保持下列条件：

- 基础来源图、参与者关系、时间顺序、依赖和约束有实质差异；只替换名字、数字或文件名不产生独立来源族。
- 派生问题、改写和相同来源的版本放在同族，不跨探索、验证、确认划分。若审阅发现同一模板造成实质相关性，应合为更大来源簇，重新计算独立样本数。
- 从历史召回、目标身份、续接决策、时间变化、可信状态、上下文传递、不需要历史、生命周期八类的固定等概率混合分布中独立抽取族类型；先冻结抽取种子与日程，再编写来源和 gold。不能根据候选表现挑选类型。
- gold、禁止结果和证据由来源确定，在模型执行前复核。评分标签不进入模型输入、索引或 worker 文件。
- 每个指标的合格来源族由题目定义决定，不能由回答结果决定。样本量只计算该指标合格的族；不同指标的合格集合不重合时，总样本需求相应增加。
- 只使用合成或另行获得授权的资料。默认不读取日常会话来补样本。保存来源谱系、审阅记录、语料和评分哈希。

对照与候选使用相同原生初始历史、模型、预算、权限、缓存、超时与重试规则。每族每次重复使用登记种子的随机 AB/BA 顺序，避免固定先后顺序与运行时段混淆。完整确认集在任一版本运行前冻结；查看细项或输出后，它只能作为已见回归集，不能继续调参后称为未见确认。

## 决策区间与连续候选

质量差值采用有界来源族均值的双侧经验 Bernstein 区间。若 n 为合格独立族数，s² 为族差值的无偏样本方差，m 为族平均差值，半宽为：

```text
h = sqrt(2 × s² × log(4/α) / n) + 14 × log(4/α) / (3 × (n−1))
CI = [max(−1, m−h), min(1, m+h)]
```

公式来自 [Maurer 与 Pontil（2009）定理 4](https://arxiv.org/abs/0907.3740)，把 [0,1] 缩放到 [−1,1]，再对两个方向分配错误概率。有效性依赖独立抽样与有界分数；作者声明有“不同主题”本身不构成独立性证据。三次重复的相关性留在族内。既有 bootstrap 可继续用于基线描述和图表，不代替本决策区间；尤其不能把小样本下全部通过产生的零宽区间解读为确定无风险。

所有正式确认比较共用 α 总额 0.05。第 j 个揭示结果的候选使用 αⱼ = 0.05 / [j(j+1)]，j 从 1 起累计，不因失败或进入下一阶段重置；所有 αⱼ 之和为 0.05。首次采用 97.5% 区间，之后更严格，因此始终满足至少 95% 的区间要求。所有必需指标均通过才允许应用；这属于交并决策，不声称各个区间同时覆盖的概率等于其单项覆盖率。

不在中途查看显著性，不按结果追加样本。修复夹具或评分缺陷时保留无效原因，同时重跑两版本；已经揭示的来源不再充当未见确认样本。

## 两种应用门槛

| 路线 | 必须通过的主指标 | 质量与资源保护 |
| --- | --- | --- |
| 质量 | 预选端到端质量差值至少 +5 个百分点，且区间下界 >0 | 其他关键质量的观测下降不超过预登记容差，默认 1 个百分点；p95 延迟和每请求平均 token 比值均 ≤1.10 |
| 效率 | 预选平均耗时或平均 token 降低至少 20%，且成对成本改善区间下界 >0 | 每个关键质量指标区间下界 >−1 个百分点；p95 延迟和每请求平均 token 比值均 ≤1.10 |

质量路线的其他质量指标仍须报告完整区间；其“观测下降不超过 1 个百分点”不能表述为已证明 1 个百分点非劣。效率路线必须正式通过非劣检验，不能仅以观测均值相同替代。

效率主指标预先登记每个逻辑请求包含全部重试的有效成本上界 B，计算各族 `(对照平均成本−候选平均成本)/B`，再使用同一有界区间。相对降幅按 `1−候选总体平均成本/对照总体平均成本` 计算，要求对照成本为正。超过登记上界、用量未知或缺失时不能裁剪、补零或事后重定标，结论为证据不足。此设计的效率主指标限于均值；p95 是固定请求混合下的经验保护指标，不把均值区间冒充 p95 区间。

本版本未启用“相对错误率下降”替代路线。若基线已接近满分，+5 个百分点不可达到，不能在看到候选结果后改口径；须在相应候选实验前另行冻结该路线。效率优化仍可依既定规则验证。

所有重要分组须分别报告，不能用总体均值掩盖超出预登记容差的退化。新增错误会话写入、跨项目污染、权限扩大、候选记忆自动确认及重复派发必须为零；生命周期和原生记录重建检查保持。单步比较与相对 B0/阶段起点的累计比较同时保留。召回率提高、模型自报完成或一次成功运行都不构成应用依据。

## 样本量与执行成本

规划备择使用真实质量改善 +8 个百分点，成对分歧 q=0.25；令族差值 D∈{−1,0,1}，P(D=1)=(q+δ)/2，P(D=−1)=(q−δ)/2，方差为 q−δ²。三次重复按完全相关规划，不把重复数当作降低独立来源需求的保证。这是事先选定的假设，不是从 B0 测得的分歧或方差。

应用门槛保持 +5 个百分点。真实收益恰为 +5 个百分点时，要求观测收益也至少 +5 个百分点，在对称连续近似下最多约有 50% 通过概率；增加样本不能使这个门槛有 80% 功效。+8 个百分点只作为规划备择，不改变应用要求。

下表是脚本的正态规划近似，以假设方差代入经验 Bernstein 半宽，目标为每项推断约 80% 规划通过概率。首次采用保守的最低数量；后续依更严格的 α 计算并向上取 8 的倍数。8 的倍数仅用于执行批次，不代表强制各类数量相等。

| 正式确认序号 | 质量路线合格族数，真实 +8pp | 规划概率 | 效率路线每个质量指标合格族数，真实差异 0 | 1pp 非劣规划概率 |
| --- | ---: | ---: | ---: | ---: |
| 1 | 1,200 | 85.1% | 50,000 | 85.9% |
| 2 | 1,352 | 80.4% | 53,040 | 80.0% |
| 3 | 1,488 | 80.6% | 57,936 | 80.0% |

首次质量确认至少含 1,200×2×3=7,200 个“版本×来源族×重复”，效率非劣至少 300,000 个；一个这样的单位可能涉及多道题、多轮及多次模型调用。该成本必须在执行前核对，不把海量改名样例凑成独立来源。效率主指标还需根据独立探索资料登记有界成本的预期效应和方差，可能需要更多族。每项约 80% 规划概率不代表全部条件同时通过也有 80%；正式实验须按登记的指标数量核算联合功效或明确更高的各项规划目标。

敏感性结果说明这些数不是普遍保证：首次质量确认在 q=0.50、真实 +8pp 时需要 1,800 族；首次 1pp 非劣在 q=0.50 时需要 85,784 族。若独立探索样本不能支持原有方差/效应假设，应在任何确认结果揭示前固定更大的样本量。某指标只有 12 或 48 个独立族，即使观测方差为零，本区间半宽仍分别约为 2.153、0.504（之后裁剪至合法范围），无法据此确认微小收益或非劣。

这些是条件化的近似规划计算，不是已经完成的候选比较、实际功效或成功保证。当前没有生成上述正式来源族，也没有消耗现有封存集。可在具备预算与独立样本来源后准备正式确认；在此之前允许按整体方案开展隔离探索，但不允许凭探索结果应用优化。

## 复现与登记

在私人助理插件目录执行下列命令，可重新计算并检查数值；默认输出到标准输出，不读取任何题目文件：

```sh
node test/evaluation/confirmation-design-analysis.js
```

可给出一个尚不存在的输出文件路径；脚本拒绝覆盖已有结果。结果保存设计和脚本的 SHA-256、数值假设、前三次确认的规划、分歧与真实效应敏感性，以及当前小样本的限制。

正式实验在执行前登记：唯一改动、对照与候选及 B0 代码哈希、模型和来源/gold/评分哈希、主指标与路线、每个指标的合格族数、固定样本量和功效假设、全部质量指标、分组容差、资源上限、随机顺序种子、超时/重试策略、分析命令和原生回归命令。记录中的样本总量至少满足每个必需指标，不能只引用上表主指标的最低数。

先完成检索阶段正向验证、真实应用与复测，再建立 B2 并开始任务上下文阶段。基础设施失败、功效不足和用量缺失均不算“连续三次合理实验无明显收益”。B0 能否放行还取决于其覆盖与运行证据；本设计只关闭“正式统计规则未定义”的缺口，不替代 B0 的功能、生命周期或性能验证。
