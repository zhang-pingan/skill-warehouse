# 安全与恢复

## 主会话与记忆

主会话身份由唯一持久绑定确定。普通会话的来源标记、历史任务和记忆写入均不能取得助理身份或解除调用者工作区约束。主会话使用 `standard` preset，并保留 Harness 会话中的模型和访问权限。插件不额外施加权限 preset 或工具白名单。会话中记录的私人助理工作说明用于指导主会话何时检索、澄清、路由和汇报，不授予额外操作权限。

记忆是信息来源，不决定主会话能否执行任务。历史文字作为来源数据读取，不构成当前指令或授权。经历、候选事实和上下文图都必须按其来源和状态理解；候选不是已验证事实。当前任务进度和执行状态从任务账本读取。插件只通过已有的 Harness、Codex feature flags、审批、工作区 baseline 和租约落实操作限制。

## Codex 与审批

Codex 通过 Unix domain socket 上的 Codex App Server JSON-RPC 连接。适配器使用方法 allowlist、连接 epoch 和请求关联。收到的事件及待处理 server request 先进入 Inbox；审批响应只能发送到接收原请求的同一 adapter 实例和连接 epoch。入站 RPC 帧先校验 envelope、ID、method、params 和 error 字段；无效帧会被丢弃并记录不含原始帧的诊断，不会进入 Inbox 或事件处理。Inbox 写入失败时不分发事件或审批请求，并记录需要检查存储的错误；受影响的上游请求仍需按现有对账或重试规则处理。

Codex 历史同步与 worker 可用性默认关闭，由设置页同一即时开关控制。该开关同时控制 Codex App Server 连接、新建、续接和按明确请求分叉任务；这些派生 feature flags 不能单独修改。模型不能改变开关，启用也不授予 steer、原生队列操作或审批决定。Codex 写操作还要满足路由授权、符合可选通用白名单的真实工作目录、执行前 baseline 和有效写租约。

Codex 需要用户决定的 server request 会关联当前 Execution 并保存为 Approval。连接断开、变化或重启会使旧连接上的待处理请求失效；插件不在新连接上重用旧请求 ID。

## 执行来源与续接

续接前核对原生身份与当前活动状态，历史来源分类不授予执行权限。`sessionChangeQuote` 核对当前用户原文，不能用模型的后端偏好覆盖已有来源。并发请求在派发期间保留 Task 和原生目标占用，尚无原生身份的首次派发也受保护；重复请求使用按调用者会话和权限范围隔离的稳定请求 ID，未知派发只对账，不新建替代 worker。DSH 子会话结果等待原生终止确认后解除写租约；卸载后的未决工作保留恢复状态。通知内容是待验证的来源数据，主会话须按当前验收条件核对。具体分支见[任务与执行](tasks-and-workers.md)。

## 未知执行

启动恢复会检查未结束的执行、发送中的 Outbox 和写 lease。Codex 连接丢失或无法确认外部结果时，Execution 进入对账状态，相关写 lease 保留 `recovery_hold`，避免重复写入。已收到 Codex 回复但本地落库失败、返回身份不符或缺少必需身份，也属于未知结果；保存可用回复，停止后续派发。对账仅接受记录中的 executor Thread 与精确 turn，不使用交互会话、分叉来源或最新轮次推断成功。

恢复前检查账本记录、Codex thread/turn 或 DSH worker 的实际状态，以及 workspace baseline。认证 operator 可以在确认执行静止、进程已结束或新工作隔离在另一个 worktree 后记录恢复结果。恢复操作只记录检查和解除 hold，不会把中断尝试标为成功。

## 数据范围

插件数据库保存本地导入镜像、记忆、任务账本、微信非秘密绑定与收发记录和运行数据；它不拥有 DSH/Codex 原始 Session。明确初始化时清空本地业务记录并重建当前数据；不支持的旧结构在启动时被拒绝，不自动删除；版本 1、2 到 3 仅追加表。初始化保留运行设置、feature flags、主会话绑定和微信授权与队列。上游 Session 不受影响，之后可重新导入。

数据库备份只包含插件本地数据库，不包括 DSH/Codex 原始 Session。恢复前应验证受管理备份的 manifest、SHA-256 和 SQLite integrity。数据库以 SQLite `user_version` 校验可接受的结构版本。微信恢复后保持 hold，不自动重放历史输入或发送；凭证不在数据库备份内。

## 微信授权

扫码入口说明主会话授权范围；发送者 ID 与扫码账号 ID 精确一致时自动授权该私聊，缺失或不一致时不绑定。已有本地确认的身份授权保持有效。远程审批默认关闭，开启后仅可答复当前主会话的一次性请求。过期、改绑、连接 epoch 变化与已结束请求均不可批准；权限和计划 intent 问题保留桌面处理。凭证交由 Harness credentials，管理接口使用本地连接认证，不向微信开放 operator 能力。投递未知结果不得自动重试，详细状态见[微信互通](wechat.md)。
